## 🦾 关于我

> 🫠 上班，想死 —— 但代码还是要写的。

白天让机械臂动起来，晚上写点自己想写的。常年在这几件事之间来回横跳：

| | |
|---|---|
| 🦾 **运动规划** | ROS 2 / MoveIt 2，从 URDF 建模到轨迹规划再到真机执行的一整条链路 |
| 👁️ **机器视觉** | OpenCV / YOLO，手眼标定、目标检测、位姿估计 |
| 🛠️ **工程化** | C++ / Python / Qt，把重复劳动一件件写成工具 |
| 🎮 **不务正业** | 游戏自动化脚本、骑行、到处乱跑 |
